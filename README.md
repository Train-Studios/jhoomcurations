# Jhoom Curations by Amilohit

A responsive, static dance choreography website built with React, TypeScript, Vite/vinext, Tailwind CSS, and Lucide React icons.

## Run locally

1. Install dependencies with `npm install`.
2. Start the local site with `npm run dev`.
3. Open the local URL printed in the terminal.

Create a production build with `npm run build`.

## Free deployment on Vercel

1. Push this project to a Git repository.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Keep the detected build settings and select **Deploy**.
4. Add your custom domain in the Vercel project settings when ready.

No backend, database, environment variables, or payment setup is required.
